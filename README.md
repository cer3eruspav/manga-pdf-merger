# Manga PDF Merger

เครื่องมือ command-line สำหรับเรียงไฟล์ PDF ตามเลขตอน ลบหน้าเครดิตที่รู้จักจากชุดภาพอ้างอิง แล้วรวมเป็น PDF เดียว

> **ข้อจำกัดสำคัญ:** โปรแกรมนี้ไม่ได้ใช้ AI หรือ OCR เพื่อค้นหาหน้าเครดิตใหม่โดยอัตโนมัติ แต่เปรียบเทียบภาพหน้ากระดาษกับภาพใน `credit_images` เท่านั้น ถ้าเจอหน้าเครดิตรูปแบบใหม่ ต้องเพิ่มภาพหน้านั้นเป็นภาพอ้างอิงก่อน โปรแกรมจึงจะรู้จัก

## ความสามารถ

- เรียงไฟล์ตามเลขตอนที่อ่านจากชื่อไฟล์ และแทรกหน้าคั่นระหว่างตอน
- เปรียบเทียบทุกหน้าใน PDF กับภาพอ้างอิง รวมถึงภาพที่อยู่ในโฟลเดอร์ย่อยของ `credit_images`
- ลบหน้าที่มีภาพตรงกับภาพอ้างอิงก่อนรวมไฟล์
- หากตรวจภาพไม่สำเร็จ โปรแกรมจะแจ้งเตือนและใช้ PDF ต้นฉบับต่อ โดยไม่ลบหน้าแบบเดาสุ่ม

การจับคู่เป็นการเปรียบเทียบภาพ ไม่ใช่การอ่านข้อความในหน้า จึงอาจไม่รู้จักหน้าเครดิตที่ถูกครอป จัดวางใหม่ หรือเปลี่ยนรูปแบบจากภาพอ้างอิงมาก และอาจต้องเพิ่มภาพอ้างอิงหลายแบบเพื่อให้ครอบคลุม

## ข้อกำหนด

- Windows
- Python 3.10 ขึ้นไป
- [Poppler for Windows](https://github.com/oschwartz10612/poppler-windows) สำหรับแปลงหน้า PDF เป็นภาพ

## ติดตั้งบน Windows ใหม่

1. ติดตั้ง Python 3.10 ขึ้นไปจาก [python.org](https://www.python.org/downloads/windows/) และเลือกติดตั้ง Python Launcher (`py`) ด้วย
2. ดาวน์โหลด Poppler for Windows แล้วแตกไฟล์ จากนั้นเพิ่มโฟลเดอร์ `Library\bin` ของ Poppler ลงใน `PATH` ของ Windows หรือแก้ `POPPLER_PATH` ใน `merge_manga.py` ให้ชี้ไปยังโฟลเดอร์นั้น
3. ดาวน์โหลดหรือคัดลอกโฟลเดอร์โปรแกรม โดยเก็บ `merge_manga.py`, `run.bat` และ `credit_images` ไว้ด้วยกัน
4. เปิด PowerShell ในโฟลเดอร์โปรแกรม แล้วติดตั้งไลบรารีที่ต้องใช้:

```powershell
py -3 -m pip install -r requirements.txt
```

ไม่ต้องติดตั้ง Tesseract หรือ OCR engine เพิ่ม โปรแกรมใช้การเทียบภาพกับไฟล์ใน `credit_images` ไม่ได้อ่านข้อความเพื่อค้นหาหน้าเครดิตใหม่

## วิธีใช้

วิธีที่ง่ายที่สุดคือสร้าง Shortcut ของ `run.bat` แล้วนำ Shortcut ไปไว้ในโฟลเดอร์ที่เก็บ PDF จากนั้นเลือกไฟล์ PDF ที่ต้องการรวมแล้วลากไปวางบน Shortcut โปรแกรมจะสร้าง PDF ผลลัพธ์ในโฟลเดอร์ของไฟล์ PDF ตัวแรก

หรือเรียกจาก PowerShell โดยระบุไฟล์ PDF:

```powershell
py -3 merge_manga.py "C:\Manga\Series ตอนที่ 1.pdf" "C:\Manga\Series ตอนที่ 2.pdf"
```

โปรแกรมอ่านเลขตอนจากชื่อไฟล์ จึงควรใส่เลขตอนให้ชัดเจน เช่น `Series ตอนที่ 1.pdf`, `Series ตอนที่ 2.pdf` หรือ `Series Chapter 1.pdf`

## เพิ่มภาพอ้างอิงหน้าเครดิต

1. เปิด PDF ที่มีหน้าเครดิต แล้วบันทึกภาพของหน้านั้นเป็น PNG, JPG, JPEG หรือ WEBP
2. วางภาพไว้ใน `credit_images` หรือโฟลเดอร์ย่อยภายในนั้น
3. รันโปรแกรมอีกครั้งกับ PDF ที่ต้องการตรวจ

ใช้ภาพอ้างอิงที่เห็นเนื้อหาหน้ากระดาษครบและชัดเจนที่สุด การเพิ่มภาพอ้างอิงไม่แก้ไขหรือลบภาพเดิมในโฟลเดอร์ โปรแกรมโหลดภาพจากโฟลเดอร์ย่อยได้ด้วย ควรเพิ่มเฉพาะภาพที่มีสิทธิ์ใช้งานและเผยแพร่

## ความปลอดภัยของไฟล์

ก่อนย้ายต้นฉบับ โปรแกรมจะเขียน PDF ผลลัพธ์ลงไฟล์ชั่วคราว ตรวจว่าเปิดอ่านได้ จำนวนหน้าตรงกับไฟล์ที่นำมารวม และขนาดไฟล์ต่างจากขนาดรวมของ PDF ที่นำเข้า merger ไม่เกิน 10% แล้วจึงย้ายไฟล์ผลลัพธ์ไปยังชื่อปลายทาง ขนาดนี้คิดจาก PDF หลังกรองหน้าเครดิตและรวมหน้าคั่นแล้ว จึงไม่ใช่ผลรวมขนาดไฟล์ต้นฉบับดิบ หากชื่อปลายทางตรงกับไฟล์ต้นฉบับหรือมีไฟล์นั้นอยู่แล้ว โปรแกรมจะเลือกชื่อใหม่เพื่อไม่เขียนทับไฟล์เดิม ถ้าขั้นตอนรวม/ตรวจสอบล้มเหลว จะเก็บไฟล์ต้นฉบับไว้

เมื่อรวมและตรวจสอบสำเร็จ โปรแกรมจะส่งไฟล์ PDF ต้นฉบับที่รับเข้ามาไปยัง Recycle Bin ผ่าน `send2trash` หากต้องการเก็บต้นฉบับไว้ ให้สำรองไฟล์ก่อนใช้งาน หรือแก้ขั้นตอนนี้ใน `merge_manga.py` ก่อนรัน
